# Git から入手したあとの使い方（PC / iPad）

リズムレーンは **ブラウザ上で動く Web アプリ** です。MIDI 入力と音声の扱いが PC と iPad で異なるため、分けて説明します。

---

## 共通：リポジトリの取得と準備

### 1. ソースを手元に用意する

**Git を使う場合**

```bash
git clone https://github.com/kenji1979/idea.git
cd idea
git checkout cursor/rhythm-lane-app-d626
```

（`main` にマージ済みの場合は `git checkout main` のみでよいです。）

**Git を使わない場合**

GitHub の該当ブランチページから **Code → Download ZIP** で ZIP を落とし、解凍してフォルダを開きます。

### 2. Node.js を入れる

**LTS 版の Node.js**（例: 20.x または 22.x）をインストールしてください。  
インストール後、ターミナルで次が動けば準備完了です。

```bash
node -v
npm -v
```

### 3. 依存パッケージのインストール

プロジェクトのルート（`package.json` があるフォルダ）で:

```bash
npm install
```

---

## PC で使う（推奨）

TD-11 を **USB で PC に接続**し、ブラウザでアプリを開く構成です。Web MIDI / Web Audio の対応が確実です。

### 手順

1. **TD-11 と PCを USB ケーブルで接続**する。  
2. プロジェクトルートで開発サーバーを起動する。

   ```bash
   npm run dev
   ```

3. ターミナルに表示された URL（多くの場合 `http://localhost:5173`）を **Chrome または Edge** で開く。  
4. ブラウザが **MIDI へのアクセス**を聞いてきたら **許可**する。  
5. アプリで課題とテンポを選び、**はじめる** を押す。  
6. ヘッドフォンやスピーカーを PC または TD-11 側に合わせて接続し、メトロノーム音が聞こえる状態にする。  
7. **せってい** でキック／スネア／ハイハットの **MIDI ノート番号** が自分のモジュールと合っているか確認する（ずれていると反応しない）。

### 本番ビルドだけ動かす場合

```bash
npm run build
npm run preview
```

表示された URL を Chrome / Edge で開きます。

### うまくいかないとき（PC）

- **MIDI が未接続**と出る → ケーブル、TD-11 の電源、別の USB ポートを確認。  
- **許可しても反応しない** → ブラウザを Chrome / Edge に変える。  
- **音が出ない** → OS の出力デバイス、ブラウザのタブがミュートになっていないか確認。

## iPad で使う

iPad は **Safari の Web MIDI 対応状況**や、**USB MIDI の取り回し**が OS / ブラウザのバージョンに依存します。次の **A / B** のどちらかを想定してください。

### A. iPad は「画面だけ」、MIDI は PC（現実的でおすすめ）

MIDI は **PC に TD-11 を USB 接続したまま**、iPad は **同じ家の Wi‑Fi** 上で PC が出している開発サーバーの URL を開いて操作・閲覧だけ行う、という使い方です。

1. PC でリポジトリを clone 済みのフォルダに移動し、LAN 向けにサーバーを起動する。

   ```bash
   npm run dev:lan
   ```

2. ターミナルに `http://192.168.x.x:5173` のような **PC のローカル IP** が表示されるので、その URL をメモする。  
3. iPad の **Safari** でその URL を開く（PC のファイアウォールが 5173 をブロックしている場合は許可する）。  
4. **MIDI 許可**を聞かれたら許可する（挙動はブラウザ次第。MIDI は PC側の接続が使われる想定で動く場合と、制限される場合があります）。  
5. もし iPad から MIDI が使えない場合は、**PC のブラウザで演奏・判定**し、iPad は譜面や家族用のサブ画面として使う運用に切り替えてください。

> **ポイント**: このアプリの判定は **メトロノームを鳴らしているマシンのブラウザ** のオーディオクロック基準です。TD-11 を PC に繋いでいるなら、**演奏とメトロノームの聞き取りは PC 側で行う**のが一番確実です。

### B. iPad 単体 + TD-11（USB）（上級者向け）

1. iPad と TD-11 を **Apple 純正の USB カメラアダプタ等**で接続できるようにする（機種によっては給電が必要）。  
2. iPad で **対応ブラウザ**（Web MIDI が有効なもの）を使う必要があります。**Safari だけでは環境によっては Web MIDI が使えない**ことがあります。動作しない場合は **A の構成（PCにMIDI）** に戻すのが安全です。  
3. 動作確認が取れたブラウザで `npm run dev:lan` で立てた PC の URL、または iPad 上でホストできる静的サーバー経由の `https` で開く、など環境に合わせてください。

## コマンド一覧（再掲）

| コマンド | 用途 |
|----------|------|
| `npm install` | 初回のみ依存関係インストール |
| `npm run dev` | PC 本体のブラウザ用（localhost） |
| `npm run dev:lan` | 同一 Wi‑Fi の iPad などからアクセスしやすいホスト |
| `npm run build` | 配布用ファイルを `dist/` に生成 |
| `npm run preview` | ビルド結果の確認用サーバー |
| `npm test` | 自動テスト |

---

## 注意（再掲）

- 拍の基準は **アプリ内メトロノーム**です。TD-11 のメトロノームと二重に鳴らすと分かりにくいので、TD-11 側のクリックはオフ推奨です。  
- ハイハットの **オープン／クローズ切り替えを要する課題はありません**。
