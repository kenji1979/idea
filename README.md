# ベース指板・音階ラボ

初心者が **4弦ベースの指板** と **よく使う音階** を視覚的に学ぶための静的サイトです。ルート音とスケールを選ぶと、指板上の該当音が色分けされ、マスをクリックすると簡易的な音が鳴ります。

## 使い方

1. `index.html` をブラウザで開く（ローカルファイルのままで可）。
2. またはプロジェクト直下で次のようにすると同一ネットワークからも確認しやすいです。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 構成

| ファイル | 内容 |
|---------|------|
| `index.html` | ページ構造・日本語の解説 |
| `css/styles.css` | レイアウトと指板の見た目 |
| `js/app.js` | 音名計算、スケール表示、クリックで簡易発音（Web Audio API） |

チューニングは一般的な **E–A–D–G（低音から）** です。指板の行はタブ譜に合わせ、上から **G・D・A・E** の順です。

## ライセンス

学習用サンプルとして自由に改変してください。
